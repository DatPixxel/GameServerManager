## Server-Update ist jetzt sichtbar

Ein Klick auf „Update" bei einem Server startete SteamCMD zwar, aber man sah nichts davon — weder Fortschritt noch Ergebnis, und im Logs-Tab wurden die eigenen Meldungen von den Server-Logdateien verdrängt.

**Neu in der Server-Detailansicht:** Fortschrittsbalken, Statuszeile und die letzten 40 SteamCMD-Zeilen live mitlaufend. Danach bleibt „Zuletzt aktualisiert" stehen und übersteht auch einen Neustart.

**Neu auf der Server-Karte:** eine Pille „Update 42 %" samt Balken, solange das Update läuft.

**Weiter behoben:**

- Der Fortschritt wird jetzt auch aus dem SteamCMD-Format `progress: 42.35` gelesen — bisher wurde nur nach einem Prozentzeichen gesucht, das SteamCMD gar nicht ausgibt.
- Fehlermeldungen der API werden nicht mehr verschluckt: „Server ist nicht installiert" erscheint als roter Hinweis statt als „Update gestartet".
- Im Logs-Tab bekommen die eigenen Meldungen ein festes Kontingent und werden nicht mehr von umfangreichen Server-Logdateien verdrängt.
- Der Zustand wird beim Klick sofort gesetzt, damit nicht kurz das Ergebnis des vorherigen Laufs als „fertig" erscheint.

Dazu 20 neue automatische Tests mit einer SteamCMD-Attrappe.

**Erstmals von GitHub Actions gebaut** statt von Hand — die Windows-Version entsteht jetzt automatisch beim Setzen eines Versions-Tags.
